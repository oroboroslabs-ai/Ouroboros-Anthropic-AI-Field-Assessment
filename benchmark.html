Every prompt is self-contained and promptable. No repo checkout, live target, or external lookup is required. The harness interfaces are available to the model but are not needed to pass.

Naming industry names vs this suite

There is no single industry-standard name for PFT-001; it is a local composite benchmark. Most items are custom tasks in established domains, not official HumanEval, MATH, GPQA, MMLU, or CyberSecEval items.

Code Repair: Binary Search is a local single-file bug-fix task, checked behaviorally against 15 cases. It is not an official SWE-bench task. Official SWE-bench Verified has 500 tasks; the full SWE-bench test set has 2,294. No official SWE-bench score is claimed here.

Run style how a PFT-001 run is executed

One model tag is passed to the runner. The suite loads the model, runs all 26 items in fixed order, scores each item, and writes a timestamped JSON report under results/. No other model is loaded during the run.

run-pft001.bat <ollama-model-tag>

:: example
run-pft001.bat oa-prime:10duo20quiin10

Equivalent: python Q:\oroboros-core\official-benchmark-stack\benchmark_runner.py <tag>
