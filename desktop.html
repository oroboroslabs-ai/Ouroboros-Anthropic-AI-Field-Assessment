Install after download

1. Run OA-Claude-Desktop-Setup-1.0.0.exe
2. Choose the install directory
3. Launch OA Claude Desktop
4. Add a model: ollama pull <model> (or choose a local .gguf)
5. Select the model in Chat

The free build includes the agent and harness. Voice and Communications remain locked and are sold separately.
